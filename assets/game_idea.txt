================================================================================
ИДЕЯ
================================================================================

Игрок отправляется в путешествие по бесконечному вулканическому миру, где сама земля постоянно меняется под воздействием жара. Каждый его шаг оставляет за собой раскалённый след, который постепенно остывает и проходит несколько температурных стадий.

Главная особенность игры заключается в том, что след начинает влиять на окружающий мир не сразу, а спустя некоторое время. Пока игрок продолжает движение, ранее пройденные участки постепенно превращаются из жидкой магмы в тлеющие угли, затем — в раскалённый металл, а после — в прочный обсидиан.

Практически все элементы окружающего мира реагируют именно на текущее состояние следа. Одни природные образования становятся проходимыми только рядом с горячими участками, другие активируются лишь после полного охлаждения маршрута.

Игроку приходится постоянно планировать не только направление движения, но и момент возвращения к уже пройденным участкам, используя изменения окружающей среды для открытия новых путей.

Каждый маршрут становится последовательностью событий, разворачивающихся во времени, благодаря чему игровой процесс сочетает простое управление с глубокими пространственно-временными головоломками.

Управление построено по принципу One-Touch.

своевременно менять маршрут;
учитывать скорость охлаждения следа;
рассчитывать момент возвращения.

Простое управление позволяет сосредоточиться на решении игровых задач.

Главным ресурсом является время.

сколько времени потребуется следу для охлаждения;
когда определённый участок перейдёт в следующую стадию;
насколько быстро необходимо вернуться к уже проложенному маршруту.

Каждая ошибка приводит к изменению окружающей среды и заставляет искать новое решение.

Чем сложнее уровень, тем больше взаимосвязанных маршрутов приходится использовать одновременно.

ТЕМПЕРАТУРНЫЙ СЛЕД

Главная механика игры построена вокруг постоянно изменяющегося следа, который игрок оставляет после каждого шага.

След не меняет окружающий мир мгновенно.

После появления он начинает постепенно охлаждаться, проходя несколько последовательных стадий.

Каждая стадия обладает собственными свойствами и позволяет взаимодействовать с различными объектами уровня.

Игрок постоянно рассчитывает, когда определённый участок достигнет необходимого состояния.

СТАДИИ ОХЛАЖДЕНИЯ
Раскалённая магма

Самая горячая стадия следа.

Особенности:

излучает яркое свечение;
плавит ледяные образования;
активирует огненные механизмы;
освещает окружающую местность;
отпугивает некоторых существ.
Тлеющие угли

След постепенно начинает остывать.

Особенности:

сохраняет остаточное тепло;
привлекает определённых существ;
активирует часть древних механизмов;
позволяет поддерживать работу отдельных устройств.
Раскалённый металл

След приобретает плотную металлическую структуру.

Особенности:

проводит энергию;
взаимодействует с магнитными минералами;
соединяет энергетические цепи;
приводит в действие древние конструкции.
Остывший обсидиан

Последняя стадия жизненного цикла следа.

Особенности:

образует прочную поверхность;
выдерживает большой вес;
позволяет перемещать тяжёлые объекты;
используется как временный мост через опасные участки.

Через некоторое время обсидиановый след постепенно исчезает, освобождая место для новых маршрутов.

Различные поверхности обладают собственной теплопроводностью.

Игроку необходимо учитывать свойства каждого материала.

Например:

Вулканический песок

Долго удерживает высокую температуру.

Базальт

Остывает значительно быстрее остальных материалов.

Металлическая руда

Усиливает температуру проходящего по ней следа.

Обсидиановые плиты

Продлевают существование полностью охлаждённого следа.

Пепельные равнины

Ускоряют разрушение маршрутов.

ВЗАИМОДЕЙСТВИЕ С ОКРУЖАЮЩИМ МИРОМ

Практически каждый объект реагирует на текущую температуру следа.

Игрок постепенно изучает особенности каждого элемента.

Ледяные образования

Разрушаются исключительно под воздействием максимально горячего следа.

После таяния открываются новые проходы.

Магнитные минералы

Работают только рядом с раскалённым металлом.

Они способны:

передвигать платформы;
открывать проходы;
изменять направление мостов;
активировать механизмы.
Каменные валуны

Могут перемещаться только по полностью остывшему обсидиану.

Иногда используются для открытия новых путей.

Лавовые потоки

Изменяют направление движения игрока.

Некоторые маршруты можно пройти только после их частичного охлаждения.

Разломы

Разделяют территорию.

Для их преодоления необходимо правильно использовать различные стадии следа.

ДРЕВНИЕ КУЗНИЦЫ

По всему миру расположены древние кузницы.

Каждая кузница реагирует исключительно на определённую температуру.

Некоторые начинают работать только при контакте с магмой.

Другие требуют присутствия тлеющих углей.

Третьи используют исключительно раскалённый металл.

После активации кузницы могут:

открывать проходы;
создавать мосты;
изменять структуру уровня;
запускать новые механизмы.

Количество активных механик увеличивается постепенно, сохраняя читаемость игрового процесса.

Баланс сложности

Каждый новый регион добавляет только одну основную механику.

После её освоения появляются дополнительные комбинации с уже известными элементами.

Это позволяет избежать перегрузки игрока новой информацией.

Баланс наград

Исследование секретных областей приносит дополнительные награды, но не является обязательным условием прохождения.

Редкие реликвии ускоряют развитие, однако не делают прохождение слишком простым.

Каждое улучшение усиливает игрока постепенно, сохраняя интерес к дальнейшему исследованию мира.

Баланс повторных прохождений

Каждый уровень содержит:

дополнительные секреты;
альтернативные маршруты;
скрытые области;
коллекционные предметы;
дополнительные испытания.

Благодаря этому повторное прохождение остаётся интересным даже после полного завершения основной кампании.

УСЛОВИЕ ПОРАЖЕНИЯ

Уровень считается проигранным, если игрок оказывается в ситуации, когда дальнейшее продвижение невозможно из-за неверно спланированного маршрута или использования механик в неправильной последовательности.

После поражения уровень можно мгновенно начать заново, применив новую стратегию.

ЦЕЛЬ ИГРЫ

Основная цель игрока:

исследовать древний вулканический мир;
научиться использовать все стадии температурного следа;
решать пространственно-временные головоломки;
активировать древние механизмы;
находить редкие реликвии;
открывать новые регионы;
собирать игровые коллекции;
выполнять ежедневные задания;
полностью изучить тайны древней вулканической кузницы.
Прогресс измеряется:
количеством пройденных уровней;
процентом исследования мира;
количеством найденных секретов;
числом собранных реликвий;
количеством открытых природных зон;
количеством активированных древних механизмов;
заполнением энциклопедии существ;
процентом завершения всех игровых коллекций.
