# Cinderforge Trail

Cinderforge Trail is a one-touch volcanic route puzzle. Guide a lone traveller
across cooling lava fields: every tap lays the next stretch of trail, and the
path only holds while the ground is still warm. Plan the whole route before the
rock sets, melt frozen gates, light the forges and reach the summit in as few
moves as par allows.

## Features

- Hand-crafted campaign across eight volcanic regions with escalating puzzles.
- One-touch controls — tap to extend the trail, undo and restart at any time.
- Collect relics and creatures, complete daily quests, and upgrade at the forge.
- Full offline play: all progress is stored on the device, no account required.
- Records, statistics, achievements and a codex that tracks everything you find.

## Building

```bash
flutter pub get
flutter run           # debug on a connected device
flutter build ipa     # iOS release
```
